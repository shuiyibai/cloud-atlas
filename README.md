# Cloud Atlas · 云图 MVP v3

这一版改成“照片地图”原型，不再进行3D建模。

## 已实现
- 首页是一整张世界地图
- 地图上的云使用用户真实照片作为贴图，不使用云 Emoji
- 手机 Safari 可以拍摄云照片
- 可以从 iPhone 本地相册/文件选择云照片
- 可以尝试获取当前位置
- GPS 不可用时，可以直接在世界地图上手动点选云的位置
- 云照片和位置记录优先保存到当前浏览器 IndexedDB
- 点击地图上的云可以查看照片
- 用户可以删除自己的云照片和对应的本地记录
- 删除后地图上的对应云标记也会消失

## 当前限制
这是本地优先 Demo。不同设备、不同浏览器之间不会自动共享云。
GitHub Pages 只负责网页代码。下一阶段如果要让全球用户看到同一张云地图，需要接入后端数据库和图片存储，例如 Supabase。
